# Inbox

Drop anything here. Voice-to-text dumps are fine. One file per idea, named `YYYY-MM-DD-short-title.md`.

A useful shape, when you have the energy for it:

```
What I want:
Why / what problem it solves:
Who it is for:
What done looks like:
Anything that must not change:
```

The morning run reads every file not listed in `PROCESSED.md`, files it into `OPERATING.md`, and turns build instructions into `specs/<slug>.md`. Nothing is lost between bursts.
